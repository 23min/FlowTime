# Devcontainer

FlowTime's devcontainer is generated by devcontainer-kit (`gh:23min/devcontainer-kit`). The
answers that produced it are in `.copier-answers.yml` at the repo root, and
[`.devcontainer/README.md`](../../.devcontainer/README.md) describes what the container holds and
how it starts. Change an answer with `uvx copier update`; project steps belong in
`.devcontainer/project/`.

What is FlowTime's own:

- `.devcontainer/project/post-create.sh` installs the .NET 9 runtimes the projects target and
  Roslynator, then runs `dotnet restore`, `dotnet workload restore` and the UI's `pnpm install`.
- `.devcontainer/devcontainer.json` carries hand edits that `copier update` merges, each with its
  reason beside it: the debugger's ptrace capability, `MSBUILDNOINPROCNODE`, and the API ports
  pinned for the Blazor UI.

For cleanup, disk pressure and what survives a rebuild, see
[devcontainer-maintenance.md](./devcontainer-maintenance.md).
